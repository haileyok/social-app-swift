# RichText — ported test manifest

Maps the TypeScript sources this package ports to the Swift tests that cover
them. Swift tests use Swift Testing (`import Testing`).

Sources are pinned to `@bsky/sdk@1.1.0` — the version the RN app pins — and the
`@bsky/sdk/richtext` module is the reference engine.

## Golden suite (ground truth)

`Packages/TestSupport/Fixtures/Golden/richtext.json`, generated by
`tools/golden-gen` from the real TS engine. Each case runs the Swift engine over
`input.text` and compares facet byte ranges + features, `segments()`, and the
`UnicodeString` lengths and index conversions against the recorded TS output.

| Swift test | Cases |
|---|---|
| `GoldenFixtureTests.loadsCases` | fixture decodes; 15 cases present |
| `GoldenRichTextTests.matchesGolden` | all 15: `plain`, `url-simple`, `url-trailing-punctuation`, `url-with-query-and-fragment`, `mention`, `hashtag`, `mixed-facets`, `cjk-plus-url`, `family-emoji-then-url`, `flag-emoji-pair`, `combining-diacritics`, `emoji-skin-tone`, `multiline`, `no-facets-punctuation-only`, `long-grapheme-count` |

## TS unit tests ported 1:1

The RN repo has **no** sibling test files for the ported modules:
`src/lib/strings/__tests__/` contains only `bidi.test.ts`, `errors.test.ts` and
`text-direction.test.ts`, none of which touch richtext. `rich-text-detection.ts`,
`rich-text-manip.ts`, `rich-text-helpers.ts` and `url-helpers.ts` are untested
upstream.

Because there is nothing to port 1:1, the behaviour of those modules is pinned by
tests whose expected values were produced by **running the original TypeScript
under node** and recording the output verbatim. Every such suite is marked below.

| Swift test | Upstream behaviour pinned | Expectations from |
|---|---|---|
| `DetectLinkablesTests.*` | `detectLinkables` (10 cases) | node run of the TS original |
| `RichTextManipTests.toShortUrlCases` | `toShortUrl` (9 cases) | node run of the TS original |
| `RichTextManipTests.shortenLinks*` | `shortenLinks` | node run of the TS original |
| `RichTextManipTests.stripInvalidMentions*` | `stripInvalidMentions` | TS source (no test upstream) |
| `RichTextStringTests.*` | `richTextToString`, `linkRequiresWarning`, `labelToDomain`, `isPossibleAUrl`, `isRelativeUrl` | TS source (no test upstream) |
| `RichTextLimitsTests.*` | `MAX_GRAPHEME_LENGTH` and `isOverMaxGraphemeCount` | RN `constants.ts`, `helpers.ts` |

The golden fixture covers 15 inputs; these cover the branches it does not reach.
