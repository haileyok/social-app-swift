# Moderation port: tests-ported manifest

Maps the TypeScript engine under `@bsky/sdk@1.1.0` (`dist/moderation/`) to the
Swift port in `Sources/Moderation/` and its tests.

Ground truth for behavior is the golden corpus generated by `tools/golden-gen`
from the real TypeScript engine: `Packages/TestSupport/Fixtures/Golden/moderation.json`
(28 cases, regenerate with `npm run generate` in `tools/golden-gen`).

## Known divergences from the TypeScript engine

- `projectCause` in `tools/golden-gen/generate.mjs` branches on `'muted-word'`
  while the engine emits `'mute-word'`, so the `matches` field never reaches the
  golden file. The Swift projection mirrors the *output*, not the dead branch.
- The engine's `Match` record is `{word, predicate}`; Swift models it as
  ``MutedWordMatch`` (`word` + `matchedValue`) since `predicate` carries no
  engine meaning beyond the matched text.
- Where the TypeScript code passes a truthy value and reads no fields
  (`addBlockingByList`), Swift takes the `ListViewBasic` itself so the list can
  be recorded as the cause source, matching what the engine actually emits.
